KnobEQ
======

つまみを回すだけで、Windows 全体の音を調整できるイコライザです。
「Equalizer APO」という無料の音響ソフトと組み合わせて使います。


■ 動作環境

  Windows 10 / Windows 11
  （.NET Framework 4.x は Windows に標準で入っているため、追加のインストールは不要です）

  Equalizer APO（無料）が、使う出力デバイス（ヘッドホンやスピーカー）に
  インストールされている必要があります。
    https://sourceforge.net/projects/equalizerapo/


■ はじめかた

  1. Equalizer APO をインストールします。
     インストールの途中で出る「Configurator」で、ふだん使うヘッドホンや
     スピーカーにチェックを入れてください（あとから変更もできます）。
  2. KnobEQ の ZIP を右クリック →「すべて展開」で、好きな場所に展開します。
  3. KnobEQ.exe をダブルクリックして起動し、つまみを回します。

  つまみの変更は、その場で音に反映されます。
  アプリを閉じても、設定した音のまま効き続けます。


■ 初回起動時に「Windows によって PC が保護されました」と表示されたら

  インターネットから入手した、署名のないアプリで表示される確認画面です。
  「詳細情報」をクリックし、「実行」を押すと起動できます。


■ 操作

  ・上下ドラッグ        … 値を変える（Shift を押しながらで細かく）
  ・マウスホイール      … 0.5 dB ずつ変える
  ・ダブルクリック      … 0 dB に戻す
  ・EQ ON               … オフにすると補正なし（聴き比べ用）
  ・Reset               … 今のモードのつまみをすべて 0 dB に戻す
  ・右上の 3 / 6        … 3 ノブ（Treble / Mid / Bass）と 6 ノブを切り替える
  ・右上の ↔ / ↕        … 横レイアウトと縦レイアウトを切り替える
  ・右上の ♥            … 開発を応援するページ（OFUSE）を開く
  ・ヒント              … チューニングガイドを開く

  上のグラフで、今のつまみで音がどう変わるかを確認できます。
  右上の「Preamp」は、音割れを防ぐために自動で下げている全体の音量です。


■ チューニングガイド

  「ヒント」を押すと、「曇りを取りたい」「重低音の振動を感じたい」のような
  目的から、どのつまみをどれくらい回せばよいかを案内します。
  「目安を当てはめる」で、つまみをまとめて目安の値にできます。


■ 音が変わらないときは

  画面に注意が表示されている場合は、クリックすると直すための設定画面が開きます。

  ・「オーディオの機能強化」がオフ
      Windows の「設定 → システム → サウンド」で出力先を選び、
      「オーディオの機能強化」を「デバイスの既定の効果」にします。
  ・Equalizer APO が入っていない
      Equalizer APO の Configurator で、その出力先にチェックを入れます。

  このほか、音楽アプリが「排他モード」で再生しているときも EQ はかかりません。
  アプリ側の出力設定を確認してください。


■ PC に加える変更

  Equalizer APO の設定フォルダー（通常は C:\Program Files\EqualizerAPO\config）に
  次の変更を加えます。

  ・knobeq.txt を作り、つまみを動かすたびに書き換えます。
    つまみの値やモードも、このファイルに保存されます。
  ・config.txt に「Include: knobeq.txt」の 1 行を追加します。
    初回だけ、元のファイルを config.txt.knobeq-backup として保存します。
  ・Peace など、ほかのソフトの設定には触れません。


■ アンインストール

  1. config.txt から「Include: knobeq.txt」の行を削除します。
  2. knobeq.txt を削除します。
  3. 展開した KnobEQ のフォルダーを削除します。

  インストーラーは使っていないため、これでアプリの痕跡は残りません。
